## Nikke 伤害计算器导入导出格式

### 键名对照

| 位置 | 英文键 | 中文键 | 取值 |
|---|---|---|---|
| 顶层 | baseAtk | 基础攻击力 | 数值 |
| 顶层 | enemyBaseDef | 敌人基础防御力 | 数值；存在启用中的无视防御力伤害时可省略（按 0 计算） |
| 顶层 | damageType | 伤害类型 | weapon / skill / 武器 / 技能 / 武器伤害 / 技能伤害；可省略，按提供的伤害系数自动推断 |
| 顶层 | weaponDmg | 基本武器伤害系数 | 百分数（9.72 或 "9.72%"） |
| 顶层 | skillDmg | 技能伤害系数 | 百分数（250 或 "250%"） |
| 顶层 | coeffs | 系数 | 数组 |
| 系数项 | type | 类型 | 内部键或显示名 |
| 系数项 | variant | 子项 | 可省略；子项内部键或显示名（见子项对照） |
| 系数项 | name | 名称 | 可省略，默认为显示名；"" 表示空名称；名称固定的项填写无效 |
| 系数项 | value | 数值 | 百分比类写百分数（50 或 "50%"）；固定值项可省略；菜单项必须是列出的值之一 |
| 系数项 | hidden | 隐藏 | true 表示导入后为禁用状态 |

### type 对照

| 分组 | 内部键 | 显示名 | 单位 / 限制 |
|---|---|---|---|
| 攻击力 | atkIncrease | 攻击力（百分比） | % |
| 攻击力 | extraAtk | 攻击力（值） | 数值 |
| 防御力 | defReduction | 防御力降低（百分比） | % |
| 武器/技能 | collectibleNormalAtkMult | 普通攻击倍率（珍藏品） | %，仅武器伤害 |
| 武器/技能 | dualGun | 双枪 | 固定 200%，名称与数值不可修改，限 1 个；武器与技能伤害系数均 ×200% |
| 武器/技能 | stackCopy | 叠加复制 | 整数 ≥ 1，仅技能伤害，限 1 个 |
| 通用 | critDmg | 暴击伤害 | %，有子项 |
| 通用 | coreDmg | 核心伤害 | %，有子项；存在任意启用中的核心伤害（含子项）时取代基础 100% |
| 通用 | fullBurst | 全爆裂补正 | 固定 50%，名称与数值不可修改，限 1 个 |
| 通用 | distance | 优势距离 | 固定 30%，名称与数值不可修改，限 1 个 |
| 优越代码 | attributeDmg | 优越代码伤害增加 | %，有子项 |
| 蓄力 | weaponBaseCharge | 武器基本蓄力伤害 | 100 / 150 / 200 / 250 / 350（%）之一，名称不可修改，限 1 个；未添加或被禁用时蓄力整项不计算 |
| 蓄力 | collectibleChargeIncrease | 蓄力伤害倍率（珍藏品） | % |
| 蓄力 | chargeDmgIncrease | 蓄力伤害 | % |
| 攻击伤害 | dmgIncrease | 攻击伤害 | % |
| 攻击伤害 | penetrationDmg | 穿透伤害 | % |
| 攻击伤害 | continuousAttackDmg | 依次攻击伤害 | % |
| 攻击伤害 | dotDmg | 持续伤害 | % |
| 攻击伤害 | ignoreDefDmg | 无视防御力伤害 | %，启用时敌人防御力按 0 计算；兼容旧名 trueDmg / 真实伤害 |
| 攻击伤害 | projectileAttachDmg | 发射体附着伤害 | % |
| 攻击伤害 | projectileExplosionDmg | 发射体爆炸伤害 | % |
| 攻击伤害 | partsDmg | 零件伤害 | % |
| 易伤 | enemyDmgTaken | 敌人受到伤害 | % |
| 易伤 | sharedDmg | 分摊伤害 | % |

### 子项对照

| 所属 type | 子项内部键 | 子项显示名 | 名称 | 数值 | 限制 |
|---|---|---|---|---|---|
| critDmg | base | 基础 | 固定为「基础暴击」 | 固定 50% | 限 1 个 |
| coreDmg | base | 基础 | 固定为「基础核心」 | 200 / 250（%）之一 | 限 1 个 |
| attributeDmg | base | 基础 | 固定为「基础优越」 | 固定 10% | 限 1 个 |
| attributeDmg | cube | 魔方 | 固定为「魔方」 | 8.48 / 10.6 / 12.72 / 14.84 / 16.96 / 19.09（%）之一 | 限 1 个 |
