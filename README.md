# NIKKE 战斗模拟器

《NIKKE：胜利女神》非官方粉丝向战斗模拟器。在浏览器里配置队伍与敌人，模拟一场战斗的伤害输出，并查看逐条战斗日志与伤害公式。

**在线使用：** https://flyingsb.github.io/nikke-battle-simulator/

纯前端静态网页，无需安装、无需注册；所有计算都在你的浏览器内完成，账号数据不会上传到任何服务器。

---

## 基本用法

1. 打开网页，等待数据加载完成。
2. **（推荐）导入账号**：见下方「导入账号」，导入后会自动带入角色等级、装备、魔方、珍藏品与研究等级。
   不导入也可以使用，此时需要手动设置角色与装备。
3. **组队**：在中栏选择 5 名角色，可调整技能等级、装备词条、魔方等。
4. **配置敌人**：在左栏设置敌人代码（属性）、防御、核心、距离，以及按时间排列的行动（横向移动、隐藏、跳起等）。
   配置可保存为预设，也可通过「导出 / 导入敌人配置」与他人分享。
5. 点击顶栏中间的 **▶ 开始模拟**，在右栏查看结果：
   - 各角色伤害与占比
   - 战斗日志（可按角色 / 技能 / Buff 筛选）
   - 详细日志模式下，**点击伤害数值可复制该次伤害的计算公式**，粘贴到「伤害计算器」中逐项核算
6. 顶栏「📜 模拟记录」可回看最近的模拟结果。

界面支持简体中文与 English，可在右上角切换。

## 导入账号

账号数据需要从 [blablalink](https://www.blablalink.com/) 导出。项目提供了一个油猴脚本来完成这一步。

### 1. 安装脚本

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 打开模拟器，点击顶栏 **🧰 工具 → 角色数据导出 → 安装脚本**，在 Tampermonkey 弹出的页面中点击「安装」。
   （也可以直接打开 [`tools/blablalink-export.user.js`](tools/blablalink-export.user.js)。）

脚本更新后，Tampermonkey 会自动检查并更新。

### 2. 导出数据

1. 登录 [blablalink](https://www.blablalink.com/)。
2. 页面顶部会出现一个蓝色的 **下载图标**，点击打开导出面板。
3. 选择你所在的 **服务器**，点击 **导出**。
4. 浏览器会下载一个名为 `<编号>_user_character_details_<时间>.json` 的文件。

> **如果提示读取 Cookie 失败 / 未登录：**
> 在浏览器的扩展管理页面中，把 Tampermonkey 的「网站访问权限」设为「在所有网站上」，然后**完全重启浏览器**再试。

### 3. 导入模拟器

点击模拟器顶栏的 **📂 导入账号**，选择刚才下载的 JSON 文件即可。顶栏会显示「账号已加载，共 N 个角色」。

> 导出的文件包含你的账号编号与完整角色养成数据，**请不要公开分享**。

## 本地运行

项目为原生 ES modules，无需构建。用任意静态服务器在项目根目录启动即可，例如 VS Code 的 Live Server 扩展，然后访问 `http://127.0.0.1:5500`。

开发相关说明见 [CLAUDE.md](CLAUDE.md) 与 [docs/](docs/)。
