# NIKKE 战斗模拟器

《NIKKE：胜利女神》非官方粉丝向战斗模拟器。在浏览器里配置队伍与敌人，模拟一场战斗的伤害输出，并查看逐条战斗日志与伤害公式。

**在线使用：** https://flyingsb.github.io/nikke-battle-simulator/

纯前端静态网页，无需安装、无需注册；所有计算都在你的浏览器内完成，账号数据不会上传到任何服务器。

---

## 基本用法

1. 打开网页，等待数据加载完成。
2. **（推荐）导入账号**：见下方「导入账号」，导入后会自动带入角色等级、装备、魔方、珍藏品与研究等级。
   不导入也可以使用，此时需要手动设置角色与装备。
3. **组队**：在中栏选择 5 名角色，可调整技能等级、装备词条、魔方等。
4. **配置敌人**：在左栏设置敌人代码（属性）、防御、核心、距离，以及按时间排列的行动（横向移动、隐藏、跳起等）。
   配置可保存为预设，也可通过「导出 / 导入敌人配置」与他人分享。
5. 点击顶栏中间的 **▶ 开始模拟**，在右栏查看结果：
   - 各角色伤害与占比
   - 战斗日志（可按角色 / 技能 / Buff 筛选）
   - 详细日志模式下，**点击伤害数值可复制该次伤害的计算公式**，粘贴到「伤害计算器」中逐项核算
6. 顶栏「📜 模拟记录」可回看最近的模拟结果。

界面支持简体中文与 English，可在右上角切换。

## 导入账号

账号数据来自 [blablalink](https://www.blablalink.com/)。由于 blablalink 的接口只能在其自身页面上调用，需要借助一个在 blablalink 页面上运行的导出工具，有两种形式，任选其一：

| 形式 | 适用 | 安装 |
|------|------|------|
| **书签版** | 手机（iOS / Android）与电脑，无需安装扩展 | 顶栏 **🧰 工具 → 角色数据导出 → 书签版**，按页面说明添加书签（[安装说明](tools/blablalink-export.html)） |
| **油猴脚本** | 电脑（需 [Tampermonkey](https://www.tampermonkey.net/)） | 顶栏 **🧰 工具 → 角色数据导出 → 安装脚本**，在 Tampermonkey 页面点「安装」（[脚本](tools/blablalink-export.user.js)） |

两者共用同一个导出程序，更新后无需重新安装书签；油猴脚本由 Tampermonkey 自动更新。

### 一键导入（推荐）

1. 点击模拟器顶栏的 **🔗 从 blablalink 导入** → **打开 blablalink**（首次需登录）。
2. 在打开的 blablalink 页面上运行导出工具：
   - **书签版**：点击书签「Nikke 导出」。Android Chrome 需在地址栏输入书签名，再点下拉建议中带书签图标的那一项。
   - **油猴脚本**：自动开始，无需操作。
3. 页面右上角出现导出面板，自动识别服务器并拉取数据，完成后数据直接回传模拟器，blablalink 标签页自动关闭。
   模拟器提示「账号已导入，共 N 个角色」。

### 手动导入

直接打开 blablalink（不经过模拟器）时无法自动回传。运行导出工具后，在导出面板中：

- 点 **复制 JSON**，回到模拟器的「从 blablalink 导入」窗口点 **📋 从剪贴板读取**（或粘贴到文本框后点「导入」）；或
- 点 **下载 JSON**，得到 `<编号>_user_character_details_<时间>.json`，再用顶栏 **📂 导入账号** 选择该文件。

> 油猴脚本在 blablalink 顶栏添加了一个蓝色的 **下载图标**，点击即可打开导出面板。
> 自动识别失败时，可以在面板中手动选择服务器后重新导出。

> 导出的数据包含你的账号编号与完整角色养成数据，**请不要公开分享**。
> 导出工具只在你的浏览器内调用 blablalink 接口，数据只会发送到模拟器页面或保存在你的设备上。

## 本地运行

项目为原生 ES modules，无需构建。用任意静态服务器在项目根目录启动即可，例如 VS Code 的 Live Server 扩展，然后访问 `http://127.0.0.1:5500`。

开发相关说明见 [CLAUDE.md](CLAUDE.md) 与 [docs/](docs/)。
