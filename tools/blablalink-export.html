Nikke 角色数据导出 · 书签版

不用安装任何扩展，手机和电脑浏览器都能用。在 blablalink 页面点一下书签，就能导出账号角色数据并直接回传到模拟器。

安装

iPhone / iPad（Safari）

  1. 点上方「复制书签代码」。
  2. 点分享按钮 → 「添加书签」，名称改为 Nikke 导出，保存。
  3. 打开书签列表 → 「编辑」→ 点刚才的书签，把地址整段替换为复制的代码，完成。

Android（Chrome / Edge）

  1. 点上方「复制书签代码」。
  2. 点菜单里的 ☆ 收藏本页，再点「修改」：名称改为 Nikke 导出，网址整段替换为复制的代码。
  3. 使用时：在 blablalink 页面的地址栏输入 Nikke 导出，点下拉建议中带书签图标的那一项。

Android Chrome 从书签列表直接点开不会在当前页面运行，必须通过地址栏输入书签名执行。

电脑浏览器

  1. 显示书签栏（Chrome / Edge：Ctrl+Shift+B）。
  2. 把上方虚线按钮「⇣ Nikke 导出」拖到书签栏。

电脑上也可以安装 油猴脚本（需 Tampermonkey），在 blablalink 顶栏添加导出图标，并在从模拟器打开时自动导出。

使用

  1. 在模拟器顶栏点 🔗 从 blablalink 导入 → 打开 blablalink（首次需登录）。
  2. 在打开的 blablalink 页面点书签 Nikke 导出，右上角出现导出面板并自动开始。
  3. 完成后数据自动回传，blablalink 标签自动关闭，模拟器显示「账号已导入」。

直接打开 blablalink（不经过模拟器）时无法自动回传：在导出面板点「复制 JSON」，回到模拟器的导入窗口点「从剪贴板读取」；也可以「下载 JSON」后用「📂 导入账号」选择文件。

说明

  • 书签只负责从本站加载导出脚本 blablalink-export.js，脚本更新后无需重新安装。
  • 导出脚本只在你的浏览器内调用 blablalink 的接口；数据只会发送到模拟器页面，或保存在你的设备上，不会上传到其他地方。
  • 服务器自动识别（国际服 / 北美 / 日 / 韩 / 东南亚 / 港澳台），也可以在面板里手动选择。
